# افزونهٔ تقطیع چندمنبعی و پک متنی یوتیوب — نسخه آزمایشی

این تغییرات فقط پس از ادغام شاخهٔ آزمایشی با main روی اجرای بعدی اثر می‌گذارد. گزارش‌های دیدبان، رونوشت TXT، Google Sheets، پاسخ‌نما و مسیر قبلی بات بله تغییر نمی‌کنند.

## ۱. تقطیع ویدیو به @live_vtv

- منابع انتخاب کلیپ: وایرال‌های واقعی گزارش، پرسش‌وپاسخ‌های مخاطبان و محورهای کلیدی برنامه.
- قطعات همپوشان، فاقد زمان معتبر یا خارج از مدت برنامه حذف می‌شوند؛ زمان جعلی ساخته نمی‌شود.
- سقف پیش‌فرض ۸ قطعه برای هر برنامه است؛ در صورت وجود منابع معتبر کمتر، تعداد نیز کمتر خواهد بود.
- برخلاف شمار ثابت ۴ در حالت قدیمی، این حالت تعداد را بر اساس بخش‌های مستقل معتبر انتخاب می‌کند.
- فایل فشرده‌تر: حداکثر عرض ۹۶۰ پیکسل، بیت‌ریت ویدیوی حدود ۷۶۰ کیلوبیت‌برثانیه یا پایین‌تر، صوت ۶۴ کیلوبیت‌برثانیه، H.264/AAC. سرعت پخش ۱× و زمان‌های اصلی حفظ می‌شود.
- در صورت نیاز می‌توان فشرده‌سازی جدید را خاموش کرد، بی‌آنکه سایر اجزا تغییر کنند.

## ۲. کانال جدید @vtv_youtube — فقط متن

برای هر برنامهٔ فارسی حداقل ۴ موضوع مستقل در صورت وجود چهار بازهٔ معتبر انتخاب می‌شود و برای هر موضوع پیام(های) جداگانه ارسال می‌شود، شامل:
- سه تیتر پیشنهادی جذاب اما قابل دفاع و یک متن کوتاه برای کاور
- شروع و پایان و مدت دقیق نسبت به آغاز برنامه، جهت برش تدوینگر
- توضیحات فارسی مخصوص یوتیوب و English summary
- محورهای گفت‌وگو، کلیدواژه‌های سئو، هشتگ‌ها، پرسش کامنت پین‌شده و فراخوان مخاطب

تنها متد Bale sendMessage استفاده می‌شود؛ هیچ عکس، ویدیو یا فایل به این کانال ارسال نمی‌شود. بات فعلی BALE_BOT_TOKEN باید در کانال @vtv_youtube دسترسی مدیریتیِ ارسال پیام داشته باشد. قبل از ساخت کانال یا اعطای مجوز، بخش متنی خطا می‌دهد ولی سایر عملیات دیدبان ادامه خواهند داشت.

توصیه به تدوینگر: زمان‌ها به ابتدای ضبط اختصاص دارند و بهتر است در تصویر اصلی کنترل شوند. بسته‌ها متن‌های پیشنهادی برای بازبینی انسانی‌اند؛ به‌ویژه اسامی، منابع و گزارش‌های محل اختلاف تاریخی.

## ۳. تنظیمات اختیاری GitHub Actions repository variables

| Variable | Default | Meaning |
|---|---|---|
| ENABLE_YOUTUBE_PACKS | true | فعال/غیرفعال‌سازی مستقل بسته متنی |
| YOUTUBE_PACKS_AI | true | یک درخواست Gemini برای چهار بسته، با بازگشت به متن مستند هنگام خطا |
| YOUTUBE_PACKS_MODEL | gemini-3.5-flash-lite | مدل بسته‌بندی، مستقل از تحلیل دیدبان |
| DIDBAN_MAX_MIXED_CLIPS | 8 | سقف ۱ تا ۱۰ قطعه برای برنامه |
| BALE_CLIP_COMPACT | true | فشرده‌سازی فایل‌های خروجی |

در main تا قبل از تأیید این شاخه تغییری داده نشود. پس از بازبینی و عبور آزمون‌های CI، شاخه در زمان غیرپخش ادغام شود. اگر لازم شد، تنها ENABLE_YOUTUBE_PACKS=false یا BALE_CLIP_COMPACT=false قرار دهید؛ تنظیمات گزارش اصلی تغییری نمی‌کند.

## ۴. سنجش و محدودیت‌ها

برای خروجی چهار بسته، چهار موضوع با بازه‌های متفاوت و قابل استناد نیاز است؛ این سامانه برای پر کردن تعداد در برنامه‌های فاقد محتوای کافی، زمان و ادعای ساختگی نمی‌سازد. خطای ربات جدید یا مدل زبانی، به کانال گزارش‌های دیدبان سرایت نمی‌کند.
