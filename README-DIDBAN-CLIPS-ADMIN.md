# پنل تقطیع دیدبان ولایت
- مسیر گزارش‌های موجود: بدون تغییر (BALE_CHAT_ID).
- مسیر ارسال ویدئوها: فقط @live_vtv (همراه کپشن کامل)، بدون fallback به کانال گزارش‌ها.
- شمارش و کیفیت و شبکه‌های فعال از config/didban_clips.json در هر برنامه خوانده می‌شود.
- پنل ویرایش واقعی: https://github.com/sey3d-m/velayat-live-monitor/actions/workflows/didban-clip-settings.yml
- صفحه نمایش تنظیمات (در صورت فعال بودن GitHub Pages): https://sey3d-m.github.io/velayat-live-monitor/clip-admin.html
- برای ثبت تنظیمات در GitHub Actions، Run workflow را باز و مقادیر جدید را ذخیره کنید. مقادیر از اجرای بعدی اعمال می‌شود.
- بات بله باید در @live_vtv مدیر و دارای اجازه ارسال فیلم باشد.
- کیفیت واقعی با وضوح پخش منبع، ظرفیت GitHub runner و سقف حجم بله محدود می‌شود. بالاتر بودن رزولوشن تضمین‌کننده کیفیت بیشتر نیست.
- محدودیت تعداد نامزدهای معتبر: کلیپ ساختگی یا زمان جعلی ساخته نمی‌شود. اگر کمتر از عدد تنظیم‌شده موجود باشد، تعداد کمتری ارسال می‌شود.
- توجه: فعال‌سازی شبکه‌های دیگر صرفاً وقتی داده زمانی واقعی کافی باشد کلیپ تولید می‌کند.
