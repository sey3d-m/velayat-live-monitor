# دیدبان ـ دوبله صوتی خودکار بنگالی (نسخه آزمایشی)

## وضعیت و حدود
این پیاده‌سازی در شاخه مستقل آماده بازبینی است و **تا زمان ادغام در main فعال نیست**. پوشش ترجمه و کیفیت صدای واقعی روی runner باید در یک اجرای واقعی سنجیده شود؛ نصب مدل و سازگاری فایل وزن قدیمی Coqui تضمین نشده است.

- گزارش‌های موجود: بدون هیچ تغییری به کانال قدیمی (`BALE_CHAT_ID`) ارسال می‌شوند.
- کلیپ فارسی: طبق تنظیمات فعلی (۴ کلیپ) در `@live_vtv` باقی می‌ماند.
- دوبله بنگالی: فقط ۲ کلیپ موفق اول همان برنامه، با گوینده مرد، در `@double_vtv`.
- هیچ متن یا کلیپی به کانال گزارش اصلی و کانال فارسی از فرایند بنگالی اضافه نمی‌شود.
- ضبط ویدئو به سرعت طبیعی ۱× با `-c:v copy` حفظ می‌شود؛ هماهنگی لب انجام نمی‌شود.
- تنها بعد از تولید، بررسی زمان و کنترل حجم **هر دو** فایل، ارسال شروع می‌شود.
- اگر پردازش یا ترجمه شکست بخورد، فایل فارسی دست‌نخورده و کلیپ بنگالی ارسال نمی‌شود.
- اگر پس از ارسال یکی از دو ویدئو ارتباط با بله قطع شود، ممکن است انتشار جزئی رخ دهد؛ امکان تراکنش اتمی در Bot API وجود ندارد.

## منابع رایگان و مجوزها
- تبدیل گفتار به متن: `faster-whisper`، اجرای محلی روی CPU (MIT).
- ترجمه: `facebook/m2m100_418M` (MIT)؛ فارسی `fa` به بنگالی `bn`.
- گوینده **مرد**: `bangla-speech-processing/bangla_tts_male` (MIT)؛ مدل Coqui VITS.
- ساخت ویدئو: FFmpeg. مدل‌ها به‌صورت خودمیزبان از Hugging Face دریافت می‌شوند.
- بدون هزینه API یا GPU اجباری؛ اما زمان/رم GitHub Actions و دانلود مدل‌ها محدودیت واقعی دارند.

## نقاط اتصال
- `video_clips.py` در خروجی موفق نام فایل (نه آدرس خصوصی) را برمی‌گرداند.
- `velayat_monitor.py` پس از اتمام کار اصلی و پیش از پاکسازی ویدئو، `bengali_dubbing_export.export_for_dubbing()` را به‌شکل اختیاری اجرا می‌کند.
- `.github/workflows/velayat-monitor.yml` در صورت وجود دو کلیپ موفق، artifact موقت `bengali-source-<run_id>` را با نگهداری یک روز صادر می‌کند.
- `.github/workflows/didban-bengali-dub.yml` بعد از پایان موفق main به‌صورت مجزا اجرا می‌شود، شناسه و منشأ run را با GitHub API کنترل می‌کند، artifact را دریافت کرده و `bengali_dubbing.py` را اجرا می‌کند.
- فایل تشخیصی موفقیت (فقط اطلاعات ارسال) در artifact با نام `bengali-dub-status-<run_id>` ذخیره می‌شود.

## دسترسی بله
بات با `BALE_BOT_TOKEN` موجود باید در کانال `@double_vtv` مدیر و مجاز به ارسال ویدئو باشد. رمز بات در کد یا Artifact نوشته نمی‌شود. از `BALE_CHAT_ID` فارسی استفاده نمی‌شود.

## توقف و بازگشت
برای متوقف‌کردن ساخت artifact در جریان اصلی، متغیر `ENABLE_BN_DUB_EXPORT` در Workflow اصلی را به `false` تغییر دهید. برای متوقف‌کردن پردازش و ارسال، Workflow `Didban Bengali Auto Dubbing` را غیرفعال کنید یا آن را حذف نمایید. هیچ تغییر دیگری در گزارش‌های اصلی لازم نیست.

## هشدار کیفیت
این نسخه فقط ترجمه ماشینی بدون تأیید انسانی است. خطا در نام اشخاص، آیات و اصطلاحات کلامی ممکن است. بررسی نمونه‌های بنگالی واقعی پیش از اتکا به انتشار پیوسته توصیه می‌شود. در اولین اجرا نصب/بارگیری مدل مرد و زمان پردازش CPU کنترل شود.
