# دوبله خودکار دیدبان به زبان بنگالی

## منبع کلیپ
- فقط **دو کلیپ اول وایرالِ ارسال‌شده با موفقیت به @live_vtv** انتخاب می‌شوند.
- عنوان، زمان و تصویر دقیقاً متعلق به همان MP4 ارسال‌شده فارسی است؛ برای دوبله سوژه جدیدی انتخاب یا تقطیع مستقلی ساخته نمی‌شود.
- گزارش‌ها، کپشن‌های کانال دیدبان، برنامه فارسی و تنظیمات دیگر تغییری نمی‌کنند.

## مسیر معتبر تحویل (اصلاح ۱۴۰۵/۰۸/۰۳)
۱. پس از موفقیت ارسال هر کلیپ به کانال فارسی، نسخه فایل در `bengali_stage/clip_01` یا `clip_02` همراه `manifest.json` ذخیره می‌شود.
۲. بعد از اتمام مرحله مانیتورینگ، GitHub Actions با اکشن رسمی `actions/upload-artifact@v4` هر کلیپ را جداگانه بارگذاری می‌کند.
۳. بلافاصله پس از موفقیت بارگذاری هر کلیپ، `repository_dispatch` برای اجرای گردش‌کار `Didban Bengali Auto Dubbing` ارسال می‌شود.
۴. گردش‌کار مستقل، کلیپ فارسی را دریافت می‌کند، گفتار فارسی را پیاده، به بنگالی ترجمه، با صدای مرد دوبله و روی ویدئوی اصلی جایگزین می‌کند.
۵. انتشار فقط به `@double_vtv` و پس از موفقیت تمام مراحل انجام می‌شود.

**محدودیت زمانی:** شروع گردش‌کار پس از اتمام پردازش برنامه زنده و صدور کلیپ‌های فارسی است؛ نه دقیقاً در لحظه ارسال کلیپ اول. پردازش مستقل دو کلیپ پس از آپلود منتظر دیگری نمی‌ماند.

## علت رفع‌شده
از داخل subprocess پایتون توکن داخلی `ACTIONS_RUNTIME_TOKEN` ارائه نمی‌شد؛ فراخوانی `@actions/artifact` در Node با خطا شکست می‌خورد. بارگذاری اکنون توسط مرحله رسمی GitHub Actions انجام می‌شود.

## قیود
- هر کلیپ تا ۳۰ دقیقه قابل پذیرش است و سقف ارسال بله ۴۹ مگابایت در نظر گرفته شده است.
- فقط دو کلیپ فارسیِ معتبر به بخش دوبله معرفی می‌شوند؛ اگر کلیپی تأیید نشود، کلیپ جایگزین ساخته نمی‌شود.
- مدل‌های متن/ترجمه/گویش رایگان و محلی هستند اما دانلود و پردازش روی CPU زمان‌بر است؛ کیفیت ترجمه کلامی نیازمند بازبینی نمونه‌های واقعی است.
- تاریخچه ویدئوی قبلی به‌صورت خودکار بازیابی نمی‌شود؛ فایل MP4 موقت پس از اجرا پاک می‌شود.

## عیب‌یابی
- اجرای اصلی: عبارت `Bengali handoff staged confirmed viral clip`.
- مراحل `Upload first/second confirmed viral clip` و `Start Bengali dubbing` در GitHub Actions اصلی.
- گردش‌کار مستقل `Didban Bengali Auto Dubbing`: مرحله دانلود، نصب مدل، دوبله و ارسال به بله.
- گزارش نهایی `bengali_dub_output/delivery.json` فقط پس از انتشار موفق ایجاد می‌شود.

اگر دوبله غیرفعال شود، کلیپ‌های فارسی و گزارش‌های دیدبان همچنان مستقل هستند.
