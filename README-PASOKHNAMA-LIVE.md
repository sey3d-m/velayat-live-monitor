# پاسخ‌نما برخط فارسی — اجرای مستقل و غیرمسدودکننده

این افزونه هیچ تغییری در `velayat_monitor.py`، تقطیع، دوبله، ربات سردبیر و کانال‌های بله ایجاد نمی‌کند.

## زیرساخت
- آغاز خودکار: یک dispatch غیرمسدودکننده پس از اعتبارسنجی برنامه فارسی در `.github/workflows/velayat-monitor.yml`.
- پردازش موازی: `.github/workflows/pasokhnama-live.yml` با GitHub-hosted runner و FFmpeg + faster-whisper محلی روی CPU؛ بدون فراخوانی Gemini یا ایجاد هزینه API جدید.
- ذخیره جداگانه: شاخه `pasokhnama-live-data`، فایل `state/live.json`؛ هیچ فایل `docs/data/live.json` از پاسخ‌نما ۴ تغییر نمی‌کند.
- خروجی آنتن: `https://sey3d-m.github.io/velayat-live-monitor/overlay-live.html`، مناسب Browser Source نرم‌افزار OBS؛ در هر ۲۵ ثانیه وضعیت انتشار را بررسی می‌کند.

## حفاظت علمی
متن نمایش‌داده‌شده فقط یک **گزیده از رونوشت ماشینی** است و بدون تأیید انسانی به نام کارشناس یا منبع علمی نسبت داده نمی‌شود. هشدار «رونوشت خودکار و تأییدنشده» در صفحه ثابت است. این نسخه جایگزین فرایند اعتبارسنجی علمی پاسخ‌نما ۴ نیست و نباید به‌عنوان نقل‌قول دقیق، آیه یا حدیث قطعی بازنشر شود.

## محدودیت‌های عملیاتی
- دوره ضبط تقریباً ۷۵ ثانیه است؛ تأخیر واقعی علاوه بر آن به صف GitHub Actions، دانلود یا بارگذاری مدل و مدت تبدیل گفتار وابسته است. این زیرساخت کم‌هزینه معادل زیرساخت بلادرنگ تضمین‌شده تلویزیونی نیست.
- حداکثر مدت یک اجرای مستقل ۷۰ دقیقه است. برنامه طولانی‌تر یا تأخیر در شروع runner موجب ایجاد شکاف خواهد شد.
- فقط برنامه‌های معمول فارسی ۱۸:۰۰، ۱۹:۳۰ و ۲۱:۰۰ به‌صورت خودکار شروع می‌شوند؛ برنامه‌های اضافی همچنان نیازمند اعتبارسنجی جداگانه‌اند.
- چون GitHub به‌عنوان منبع داده است، تغییرها ممکن است تحت اثر تأخیر CDN قرار گیرند؛ Cloudflare در این نسخه به دلیل محدودیت ایجاد پایگاه داده جدید به کار گرفته نشده است.
- داده خام صوت و متن کامل در شاخه عمومی ذخیره نمی‌شود؛ فقط خلاصه‌ای کوتاه برای نمایش تلویزیونی منتشر می‌شود.
- تا اولین اجرای موفق برنامه فارسی، نمای زنده وضعیت «در انتظار» را نشان خواهد داد.

## بازگشت فوری بدون اختلال
برای غیرفعال‌سازی راه‌اندازی خودکار، فقط مرحله `Start isolated Pasokhnama live feed (nonblocking)` در گردش‌کار دیدبان حذف شود. هیچ تنظیم یا فایل دیگری در موتور دیدبان لازم نیست تغییر کند. شاخه داده زنده مستقل است و حذف یا خاموش‌کردن آن نباید بر سامانه اصلی اثر بگذارد.

## آزمون‌ها
آزمون انتشار خودکار صفحه `Validate and publish independent Pasokhnama OBS page`، دستور `python -m py_compile pasokhnama_live_capture.py` و `node --check docs/assets/pasokhnama-live.js` را اجرا می‌کند. آزمون راه‌اندازی صوت تا نخستین شروع واقعی برنامه فارسی انجام‌شده محسوب نمی‌شود.
