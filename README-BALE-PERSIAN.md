# پاسخ‌نما ۳ — فقط شبکه ولایت فارسی + ورود آرشیو کانال بله

این بسته **افزودنی** مخزن سالم و فعلی `velayat-live-monitor` است. موتور صدا/Gemini، فایل `velayat_monitor.py`، دریافت HLS و ارسال گزارش به بله را تغییر نمی‌دهد. بر اساس گزارش‌های واقعیِ قالب «بخش اول | خلاصه برنامه‌های زنده شبکه ولایت» و «بخش دوم | تحلیل تکمیلی برنامه‌های زنده شبکه ولایت» طراحی شده است.

## امکانات

- فقط گزارش‌های **شبکه ولایت فارسی** پردازش می‌شوند؛ گزارش‌های شبکه‌های بین‌المللی، گزارش‌های داخلی و پیام‌های نامربوط وارد آرشیو عمومی نمی‌شوند.
- از «بخش اول» نام برنامه، تاریخ، زمان رسمی، موضوع، مجری، کارشناس، خلاصه محتوای کلی و محورهای زمان‌دار استخراج می‌شود.
- از «بخش دوم» پرسش، چکیده پاسخ، نام مخاطب (اگر در گزارش آمده)، شهر مخاطب (اگر صریحاً در متن آمده) و تایم‌کد استخراج می‌شود.
- بازه تقریبی پرسش و پاسخ از **ساعت شروع رسمی برنامه + تایم آغاز پرسش/پایان پاسخ** محاسبه می‌شود و با واژه «حدود» نمایش داده می‌شود. زمان دقیق شروع صحبت کارشناس از متن بله به دست نمی‌آید.
- از وجود نام/شهر/زمانِ غایب چیزی حدس زده نمی‌شود. چون قالب فعلی دیدبان `audience_city` ندارد، شهر صرفاً وقتی در پیام بله صریح باشد قابل بازیابی است؛ برای برنامه‌های آینده باید موتور شناسایی شهر جداگانه توسعه داده شود.
- صفحه `docs/index.html` برای مخاطبان، جست‌وجو به تفکیک برنامه/سال/مخاطب/شهر، پرونده محتوایی برنامه و `/overlay.html` برای تلویزیون.
- در `docs/data/archive-YYYY.json` برای هر سال آرشیو دائم نگه داشته می‌شود، با جلوگیری از تکرار.

## نکته مهم درباره تاریخچه بله

متد رسمی `getUpdates` تاریخچه نامحدود کانال را برنمی‌گرداند؛ مستندات بله مدت نگهداری ۲۴ ساعت / ۲۰۰۰ به‌روزرسانی را اعلام می‌کنند. بنابراین **صرفاً با دادن توکن ربات یا لینک کانال، پیام‌های قدیمی به طور خودکار و قابل‌اعتماد در دسترس نیستند**. استفاده از توکن ربات فعلی برای `getUpdates` ممکن است با webhook/گیرنده دیگری تداخل داشته باشد؛ در این بسته اصلاً از `getUpdates` استفاده نمی‌کنیم.

برای واردکردن سوابق، **متن پیام‌های قدیمی همان کانال** را به شکل `.txt` یا `.json`/`.jsonl` جمع‌آوری و به برنامه ورودی بدهید. لازم نیست رمز یا توکن بله را ارسال کنید. اگر خروجی مستقیم بله در دسترس نیست، متن پیام‌ها را از کانال کپی کنید و در یک فایل UTF-8 بگذارید؛ بهتر است «بخش اول» و «بخش دوم» هر برنامه پشت سر هم باشند. داده‌های شخصی و متن خام را در مخزن عمومی GitHub قرار ندهید.

## روش نصب بدون دست‌زدن به دیدبان

۱. فایل‌های این ZIP را **در ریشه همان مخزن GitHub** قرار دهید. وقتی با GitHub آپلود می‌کنید، پوشه `.github/workflows` باید با مسیر اصلی مطابقت داشته باشد.

۲. مسیر `Settings → Pages → Source` را `GitHub Actions` بگذارید.

۳. مسیر `Actions → Publish Q&A Dashboard → Run workflow` را اجرا کنید. وقتی اولین گزارش جدید دیدبان با نام Artifact `velayat-persian-*` ساخته شود، صفحه به طور خودکار به‌روز می‌شود.

۴. نمایش آنلاین: `https://<github-username>.github.io/<repo>/`؛ خروجی تلویزیون: همان نشانی با `overlay.html`. برای بررسی گرافیک نمایشی از `?demo=1` استفاده کنید.

## اضافه‌کردن آرشیو بله (روش مطمئن)

با دریافت فایل متن/JSON قدیمی در یک محیط خصوصی، دستورهای زیر اجرا می‌شوند:

```bash
python import_bale_history.py --input /path/to/bale-messages.txt --output /tmp/persian-reports.json
python publish_site_data.py --import-file /tmp/persian-reports.json --out-dir docs/data
```

سپس فقط فایل‌های `docs/data/archive-YYYY.json` و `docs/data/index.json` حاصل (پس از مرور محتوا برای انتشار عمومی) به GitHub اضافه شوند. فایل متن قدیمی، توکن و اطلاعات داخلی در GitHub عمومی ذخیره نشوند.

### ورود کاملاً در GitHub Actions (بدون رایانه)

اگر یک نشانی **خصوصی HTTPS** برای فایل خروجی بله یا Sheets دارید، در `Settings → Secrets and variables → Actions` مقدار `HISTORY_EXPORT_URL` را تنظیم کنید؛ در صورت نیاز `HISTORY_EXPORT_TOKEN` هم به‌صورت Secret. سپس `Actions → Import Historical Archive → Run workflow` را اجرا کنید. این گردش‌کار ابتدا قالب گزارش بله را تشخیص می‌دهد و فایل خام را به‌عنوان artifact یا commit منتشر نمی‌کند. بدون وجود چنین نشانی/خروجی، اجرای گردش‌کار قادر به خواندن تاریخچه نیست. لینک صفحه کانال معادل API تاریخچه و لینک دانلود فایل خروجی نیست.

## دقت و سیاست انتشار

- **بازه زمانی تقریبی** است: ساعت شروع برنامه + تایم سؤال تا پایان پاسخ؛ لحظه دقیق آغاز پاسخ کارشناس باید از صوت تعیین شود.
- نام/شهر فقط وقتی واقعاً در گزارش ثبت شده است، منتشر می‌شود. پیش از انتشار عمومی، سیاست رضایت/حریم خصوصی مخاطبان را بررسی کنید؛ می‌توان نام خانوادگی را حذف کرد.
- در متن فعلی بخش دوم دیدبان، سؤال مجری در فهرست پرسش مخاطب قرار نمی‌گیرد؛ فقط سؤال واقعی دارای پاسخ در این آرشیو وارد می‌شود.
- اگر پیام‌های بله به دلیل محدودیت طول به تکه‌های متعدد تقسیم شده‌اند، ممکن است متن کامل آن تکه‌ها نیاز به کنارهم‌گذاری داشته باشد. تعداد موارد ناقص یا بخش دومِ بی‌همتا باید پس از ورود بررسی شود.
- تاریخ برنامه از بخش اول استخراج می‌شود؛ تاریخ انتشار پیام در بله به جای آن قرار داده نمی‌شود.
- پیام‌های تاریخچه وارد نشده‌اند: فایل ZIP دارای داده ساختگی نمایشی است، نه آرشیو واقعی کانال.

## آزمون

```bash
python -m unittest discover -s tests -v
```

فایل اصلی `velayat_monitor.py` را تغییر ندهید؛ افزونه صفحات و داده آرشیو را به مخزن سالم اضافه می‌کند.
