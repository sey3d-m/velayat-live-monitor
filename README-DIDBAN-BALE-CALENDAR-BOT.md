# ربات مدیریت تقویم دیدبان در پیام‌رسان بله

## هدف و حدود دسترسی

این ربات **فقط** نوبت‌های *اضافی* برنامه‌های تولیدی شبکه فارسی را مدیریت می‌کند؛ برنامه‌های ثابت ۱۸:۰۰، ۱۹:۳۰ و ۲۱:۰۰، ساختار پیاده‌سازی و تحلیل گزارش، تقطیع وایرال فارسی، ارسال گزارش‌ها به کانال قبلی و دوبلهٔ بنگالی تغییر نمی‌کنند.

قابلیت‌ها: افزودن یک‌باره/روزانه/هفتگی/ماهانه با مکالمهٔ فارسی، نمایش فهرست و تقویم هفته، توقف و ادامهٔ یک مجموعه برنامه، لغو یا برگرداندن فقط یک نوبت، و حذف برنامه از تقویم. دستور و تأیید فقط در **گفت‌وگوی خصوصی** مدیر مجاز پذیرفته می‌شوند.

## راه‌اندازی امن (یک بار)

۱. در بله یک **ربات مدیریتی جداگانه** بسازید. این ربات نیازی به عضویت یا مدیریت در هیچ‌کدام از کانال‌های گزارش، کلیپ فارسی یا دوبله ندارد.
۲. به تنظیمات مخزن GitHub `sey3d-m/velayat-live-monitor` → `Settings → Secrets and variables → Actions → New repository secret` بروید؛ **نام** رمز `DIDBAN_CONTROL_BOT_TOKEN` و **مقدار** آن توکن ربات جدید باشد. **توکن را در پیام چت، کانال یا فایل مخزن منتشر نکنید.**
۳. در چت خصوصی همان ربات پیام `شناسه من` یا `/id` را بفرستید. بعد از اجرای زمان‌بند، ربات شناسهٔ عددی حساب شما را پاسخ می‌دهد.
۴. رمز دوم `DIDBAN_CONTROL_ADMIN_IDS` را در همان بخش GitHub ایجاد کنید. مقدارش شناسهٔ عددی مرحله قبل است؛ برای چند مدیر اعداد را با ویرگول جدا کنید.
۵. پس از فعال‌سازی، فقط پیام‌های خصوصی حساب‌های مجاز امکان تغییر تقویم دارند. اگر توکن یا فهرست مدیران هنوز تنظیم نشده باشد، فقط بخش مدیریت ربات غیرفعال می‌ماند و دیدبان اصلی به کار ادامه می‌دهد.

**توکن ربات جدید را با توکن ربات قبلی گزارش دیدبان عوض نکنید.** ربات مدیریتی با polling کار می‌کند و اگر ربات دیگری روی همان توکن webhook یا polling فعال داشته باشد، می‌تواند تداخل داشته باشد؛ در این وضعیت برنامه مدیریتی بدون تغییر webhook متوقف می‌شود.

## فرمان‌های فارسی

- `افزودن`: ربات به ترتیب نام، ساعت شروع و پایان به وقت تهران، نوع تکرار، تاریخ شروع و پایان و در صورت هفتگی روزهای هفته را می‌پرسد. پس از نمایش پیش‌نمایش، فقط با `تایید` ثبت می‌شود.
- `برنامه‌ها`: نمایش شناسه، عنوان، بازه، تکرار و وضعیت فعال یا متوقف.
- `تقویم هفته`: فهرست نوبت‌های اضافی هفت روز بعد.
- `لغو show123`: توقف تمامی نوبت‌های آینده برنامه دارای این شناسه؛ `فعال show123`: فعال‌سازی دوباره.
- `لغو نوبت show123 1405-08-10`: حذف فقط آن تاریخ از مجموعه؛ `برگرداندن نوبت show123 1405-08-10`: بازگردانی آن تاریخ.
- `حذف show123`: حذف کامل از تقویم آینده؛ `انصراف`: کنارگذاشتن درخواست تأییدنشده.
- `راهنما` و `شناسه من`: توضیحات و شناسه حساب.

شناسهٔ خودکار پس از ثبت در پاسخ ربات و فهرست برنامه‌ها مشخص می‌شود. ساعت‌ها به وقت تهران هستند. در برنامه‌های تکراری، پایان مشخص الزامی است و فاصله آغاز تا پایان برنامه ۱۵ تا ۱۸۰ دقیقه است. زمان‌بندی برنامه ماهانه **شمسی** است؛ تاریخ شمسی یا میلادی پذیرفته می‌شود.

## حفاظت از برنامه اصلی

- فقط فایل `config/didban_extra_programs.json` و کپی نمایشی آن و شناسه پیام پردازش‌شدهٔ ربات تغییر می‌کنند؛ کد و مراحل رسانه‌ای اصلی تحت اختیار ربات نیستند.
- زمان‌های هم‌پوشان با سه برنامه ثابت فارسی یا سایر نوبت‌های ثبت‌شده مجاز نیستند.
- تمام تغییرات قبل از ثبت به تأیید مدیر نیاز دارند، در GitHub ثبت نسخه می‌شوند و قابل بازبینی و بازگردانی هستند.
- بررسی پیام‌ها از طریق **همان گردش‌کار زمان‌بندی پنج‌دقیقه‌ای تقویم** انجام می‌شود. پاسخ‌ها ممکن است چند دقیقه تأخیر داشته باشند؛ اجرای دقیق سر ساعت نیز به سرویس GitHub بستگی دارد.
- توقف یا حذف یک برنامه، **اجرایی را که قبلاً شروع شده متوقف نمی‌کند**. برای جلوگیری از شروع، لغو باید قبل از زمان برنامه و قبل از dispatch انجام شود.
- اگر احراز هویت یا API ربات کار نکند، زمان‌بند نوبت‌ها مستقلاً ادامه می‌دهد.
- برنامه‌های تولیدی باید در زمان ثبت‌شده واقعاً از همان پخش زنده شبکه فارسی پخش شوند. سامانه در این مرحله هیچ فایل ضبط‌شدهٔ مستقل یا URL جدیدی دریافت نمی‌کند.
